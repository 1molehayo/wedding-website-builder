# Activity and support

## Review recent changes

Open **Activity** to see a read-only history of important actions by admins, guests, and the system. Newest actions appear first.

You can filter the list by:

- area, such as Guests, Registry, Pages, Media, or Settings;
- who performed the action;
- an admin email address; and
- a date range.

### Apply filters

1. Choose one or more filters.
2. Select **Apply filters**.
3. Use **Previous** and **Next** if there are several pages.
4. Select **Clear** to return to the complete list.

The Activity page is useful when you need to answer questions such as:

- Who changed the page content?
- Was a guest removed?
- When was a transfer updated?
- Did an admin account change?

The history is not an undo button. Page content has its own restore option under **Page content → History**.

## Check notifications

Select the bell icon near the top-right corner to see admin notifications. Open new items and follow their link where one is provided.

## Send feedback about the app

Select **Feedback** near the top-right corner.

Use it to report:

- something that is not working;
- an improvement you would like; or
- a comment about the app.

Explain what you were trying to do, what happened, and which page you were using.

Super admins can open **Backlog** to review submitted feedback.

## Contact support

Regular admins can open **Support** from the menu to contact the super admin.

Use Support when:

- you need your sign-in email changed;
- you cannot complete an admin task;
- you need access or account help; or
- the issue contains private wedding information.

For the fastest help, include:

1. the page name;
2. the button you selected;
3. what you expected;
4. what happened instead; and
5. any reference number shown in an error message.

Do not include passwords, one-time sign-in codes, full bank details, or other sensitive information in a feedback or support message.

## If an error appears

1. Read the message and correct any highlighted fields.
2. Try the action one more time.
3. If it still fails, copy the **Reference** number shown on screen.
4. Contact support and include that number.

The reference number helps the technical team find the matching error without showing technical details to you.
