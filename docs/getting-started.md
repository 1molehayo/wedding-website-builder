# Getting started

## Sign in

You sign in with a one-time code. You do not need a password.

1. Open the [admin sign-in page](https://www.igbeyawowa.app/admin/login).
2. Enter the email address connected to your admin account.
3. Select **Send code**.
4. Open the email sent to you.
5. Copy the code from the email.
6. Return to the sign-in page and enter the code.

The code can only be used once and will expire. If it does not work, request a new one.

::: tip If you cannot sign in
Check your spam or junk folder. Also make sure you entered the same email address that received the admin invitation.
:::

## Complete your profile

The first time you sign in, the app may ask for your name.

1. Open **Profile** from the menu.
2. Enter your first name and last name.
3. Add a phone number if you want to. It is optional.
4. Select **Save profile**.

## Understand the admin menu

On a computer, the menu stays on the left. On a phone, select the menu button near the top-left corner.

- **Overview** — a quick summary of the wedding.
- **Wedding settings** — the couple's names, date, venue, website address, theme, and invitation design.
- **Page content** — the sections shown on the public wedding website.
- **Media** — private photos and private guest albums.
- **Guests** — guest details, invitations, and RSVPs.
- **Registry** — gift items, bank accounts, and transfers.
- **Activity** — a history of important changes.
- **Admins** — invite and manage admins. Only a super admin sees this option.
- **Support** — contact the super admin. Regular admins see this option.
- **Profile** — your own name, email, and phone number.
- **Backlog** — feedback received through the app. Only a super admin sees this option.

## Set up a new wedding

If the Overview page says **Wedding not set up**:

1. Select **Set up wedding**.
2. Enter the groom's name and bride's name.
3. Add the date, venue, dress code, theme, and website address if they are ready.
4. Save the setup.

The wedding date and venue can be added later. Do not enter a made-up date.

## Preview the wedding website

Select **View website** near the bottom of the menu or at the top of the
Overview page. The live published website opens in a new tab.

If you see **Set public URL** instead, open it and choose the website address first.

## Know the difference between saving and publishing

Some pages use both **Save** and **Publish**.

- **Save draft** keeps your work in the admin area. Guests do not see it yet.
- **Preview website** on Page content lets you check saved draft changes
  privately.
- **Publish** makes the saved page content live for guests.
- Saving a wedding date also keeps it private until you select **Publish date**.

Always preview important changes before publishing.

## Sign out

Select **Sign out** in the top-right corner when you are finished, especially on a shared computer.
