# Guests and RSVPs

Open **Guests** to manage the guest list, send invitations, and check responses.

The summary cards show:

- the number of guest records;
- the total number attending, including approved plus-ones; and
- the number who have not responded.

## Add a guest

1. Select **Add guest**.
2. Enter the guest's first name and last name.
3. Add an email address if you want to email the invitation.
4. Add a phone number if you want to share through WhatsApp.
5. Choose an **Invite preference**:
   - **Email**
   - **WhatsApp**
   - **Email and WhatsApp**
   - **None**
6. Add a party or household name if useful.
7. Enter how many plus-ones the guest may bring.
8. Add private notes if needed. Guests do not see these notes.
9. Select **Add guest**.

If you chose an invitation method, the app tries to send or open it after saving the guest.

## Handle guests with the same name

The app warns you if a new guest looks like someone already on the list.

- If it is the same person, select **It's the same person. Open existing**.
- If they are different people, select **These are different people** and add a private label for each person.

Example labels are “Cousin on groom's side” and “College friend”. Admin labels are never shown to guests.

## Find a guest

Use the search box to search by name, email, phone, RSVP status, household, or private notes.

Select a guest's row to view their details.

## Send an invitation to one guest

Open the guest or use their actions menu.

### Email

1. Make sure the guest has an email address.
2. Select **Email invite**.
3. If the guest was emailed before, confirm **Send again**.

The email includes the themed invitation and the guest's private RSVP link. It may also include a private photo link if the guest belongs to a photo share.

### WhatsApp

1. Make sure the guest has a valid phone number.
2. Select **WhatsApp**.
3. WhatsApp opens with a prepared message.
4. Review the message before sending it.

The WhatsApp text matches the email essentials: couple and date, wedding
website URL when available, private RSVP link, optional invitation image, and
a private photo album link when the guest is in a photo share. If the image is
not ready, you can still send the message and links.

### Copy the RSVP link

Select **Copy RSVP link** or **Copy link**. Paste the link into a message sent directly to that guest.

Each RSVP link is private. Do not post it publicly.

## Email several pending guests

1. Find the **Pending** summary card.
2. Select **Email invites**.
3. Read the confirmation carefully.
4. Select **Send emails**.

The app sends to pending guests who have an email address. Guests without an email address are skipped. A pending guest who was emailed before can receive the invitation again.

## View an RSVP

Open a guest to see:

- RSVP status;
- number attending;
- dietary notes; and
- the guest's message.

After a guest responds, their RSVP page is locked to prevent accidental changes.

## Let a guest change their RSVP

1. Open the guest.
2. Find the RSVP section.
3. Select **Unlock for update**.
4. Ask the guest to open their original RSVP link again.

## Update an RSVP for a guest

1. Open the guest.
2. Select **Edit**.
3. In the RSVP section, choose the correct status.
4. If they are attending, enter the number attending.
5. Update dietary notes or their message if needed.
6. Select **Save changes**.

The number attending cannot be higher than the guest plus their allowed plus-ones.

## Edit guest details

1. Open the guest.
2. Select **Edit**.
3. Make the changes.
4. Select **Save changes**.

The guest's private RSVP link stays connected to their record.

## Remove a guest

1. Open the guest or use their actions menu.
2. Select **Remove**.
3. Check the name in the warning.
4. Select **Remove** again.

Removing a guest cannot be undone.
