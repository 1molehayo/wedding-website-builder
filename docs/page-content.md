# Page content

Open **Page content** to build the sections on the public wedding website.

The page is made from small sections called **blocks**. You can add, edit, copy, remove, and rearrange these blocks.

## Understand the six block types

### Hero

The large opening section at the top of the website.

Use it to:

- show the couple's names, or enter a different title;
- add a short tagline such as “We're getting married”; and
- choose an image or video background;
- upload a required desktop version and an optional mobile version.

Mobile media falls back to the desktop upload. Switching between image and
video keeps both uploads; video is shown when Video is selected. Leave **Title
override** empty to use the names from Wedding settings. One Hero block is
usually enough.

### Story

A simple section for telling guests how the couple met, how the proposal happened, or another short story.

It has:

- a title; and
- a plain-text body.

Replace the example text before publishing.

### Text

A flexible section for information that needs more formatting.

Use it for:

- a welcome message;
- travel or accommodation information;
- a wedding-day schedule;
- special instructions;
- links;
- headings, lists, quotes, bold text, and other basic formatting.

Keep the text easy to scan. Use several short Text blocks instead of one very long block.

### Image

A photo section inside the public website.

It has:

- one required desktop image;
- an optional mobile image that falls back to desktop;
- an optional title; and
- an optional description.

This is different from **Media**. An Image block appears on the public wedding website. Photos in Media are used for private guest albums.

### Video

A video section with guest-controlled playback.

It has:

- one required desktop MP4 or WebM video;
- an optional mobile video that falls back to desktop;
- an optional title; and
- an optional description.

Videos can be up to 25 MB and are not compressed in the browser. Upload a
web-optimised file.

### Details

A section that reads information from **Wedding settings**.

Use the switches to choose whether it shows:

- the venue; and
- the dress code.

Edit the information itself on the Wedding settings page.

::: info Where is the gift registry block?
The gift registry is managed on the separate **Registry** page. It is not a Page content block. The app automatically adds the registry to the public website when at least one gift is visible or one cash account is enabled.
:::

## Add a block

1. Select **Add item**.
2. Review the visual previews and descriptions.
3. Choose **Hero**, **Story**, **Text**, **Image**, **Video**, or **Details**.
4. Read the confirmation notification explaining what was added.
5. The new block opens automatically.
6. Fill in its information.
7. Select **Save draft**.

Saving the draft does not change the live website.

## Open and close blocks

Select a block's name to open or close it. Use **Expand all** to open every block or **Collapse all** to close them.

## Change the website menu name

Story, Text, Image, Video, and Details blocks can appear in the public website's menu.

- Keep **Use title in nav** switched on to use the block title.
- Switch it off and enter a **Nav label** to use a shorter menu name.

Menu names longer than 20 characters are shortened. Use a clear label such as “Our story”, “Travel”, or “Venue”.

## Rearrange blocks

The order on this page is the order guests see.

1. Find the six-dot handle on the left of a block.
2. Press and hold it.
3. Drag the block above or below another block.
4. Release it in the new position.
5. Select **Save draft**.

## Copy a block

1. Open the block's actions menu.
2. Select **Duplicate**.
3. Edit the copied block.
4. Select **Save draft**.

This is useful when two sections have a similar layout.

## Remove a block

1. Open the block's actions menu.
2. Select **Remove**.
3. Select **Save draft**.

The live website stays unchanged until you publish.

## Preview changes safely

1. Finish editing.
2. Select **Save draft**.
3. Select **Preview website**.
4. Check the page on both a phone and a computer if possible.
5. Return to Page content and correct anything that looks wrong.

The preview button appears only on Page content, after a changed draft has been
saved and a public website address exists. **View website** in the sidebar and
Overview always opens the live published site.

## Publish changes

1. Save and preview the draft.
2. Select **Publish**.
3. Wait for the **Page content published** message.
4. Open **View website** and check the live page.

Publishing replaces the current live page with the draft.

## Restore an older version

The app keeps the last 10 published versions.

1. Select the small arrow beside **Publish**.
2. Select **History**.
3. Find the version you want.
4. Select **Restore**.
5. Check the restored draft.
6. Select **Publish** when you want guests to see it.

Restoring creates a draft first. It does not immediately change the live website.

## Reset the draft

**Reset draft** removes every block from the draft.

The live website remains unchanged until you publish. If you publish the empty draft, guests will see an empty page. Use this option carefully.
