# Admins and profile

## Understand the two admin roles

### Super admin

A super admin can use the whole admin area and manage other admins.

### Admin

A regular admin can manage wedding details, page content, guests, photos, and the registry. They cannot invite or remove admins.

Only give admin access to people who should be allowed to change wedding information.

## Invite a new admin

Only a super admin can do this.

1. Open **Admins**.
2. Select **Invite admin**.
3. Enter the person's first name, last name, and email address.
4. Check the email address carefully.
5. Select **Send invite**.

The person receives an email containing an acceptance link. Their status stays **Pending** until they accept.

## Resend or cancel a pending invitation

1. Open **Admins**.
2. Open the person's actions menu.
3. Choose:
   - **Resend invite** to send the invitation again; or
   - **Cancel invite** to stop the outstanding invitation.

A cancelled account can be invited again later by selecting **Send new invitation**.

## Understand admin statuses

- **Active** — the person accepted the invitation and can sign in.
- **Pending** — the invitation has not been accepted.
- **Deletion requested** — the admin asked for their account to be removed.
- **Cancelled** — the invitation was cancelled.

Tick **Show cancelled** if you need to find old cancelled invitations.

## Edit an admin's name

1. Open **Admins**.
2. Select the admin.
3. Edit their first name or last name.
4. Select **Save name**.

An admin's email cannot be changed here. Remove the old account and invite the new email address if necessary.

## Remove an admin

1. Open **Admins**.
2. Select the admin.
3. Select **Delete admin**.
4. Read the warning.
5. Select **Delete admin** again.

They lose access immediately. Their old activity remains in the history, and the email can be invited again later.

A super admin account cannot be removed from this page.

## Update your own profile

Every admin can update their own profile.

1. Open **Profile**.
2. Update your first name and last name.
3. Add or update your optional phone number.
4. Select **Save profile**.

Regular admins cannot change their own email address. They should use **Support** to request help.

A super admin can change their own email on the Profile page. The new email becomes their sign-in address, so it must be entered carefully.

## Request account deletion

Regular admins can ask a super admin to remove their account.

1. Open **Profile**.
2. Select **Request account deletion**.
3. Enter a clear reason.
4. Select **Send request**.

The account is not removed immediately. A super admin reviews the request from the **Admins** page and completes the deletion.
