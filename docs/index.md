## Who this guide is for

This guide is for anyone using the Ìgbéyàwówa admin area. You do not need technical experience.

Each page tells you:

- where to go;
- what each option means;
- which button to press;
- whether guests can see the change immediately; and
- what to check before you finish.

## A useful rule

Read confirmation messages before continuing. If the app asks you to confirm something, it usually means the action sends a message, publishes information, or removes something.
