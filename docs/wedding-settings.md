# Wedding settings

Open **Wedding settings** from the admin menu. This page controls the main wedding details used across the website, RSVP pages, and invitation emails.

## Change the couple's names

1. Find the **Couple** section.
2. Update **Groom** and **Bride**.
3. Select **Save settings** at the bottom of the page.

The names may appear on the public website and invitations.

## Set the public website address

The **Public URL slug** is the last part of the website address. For example, `ada-theo-2026` may create an address ending in `/ada-theo-2026`.

1. Enter a short address using the couple's names and, if helpful, the year.
2. Wait while the app checks it.
3. Continue only when you see **This public URL is available** or **This is your current public URL**.
4. Select **Save settings**.

::: warning Changing an existing address
Changing the public URL breaks links that you already sent to guests. Change it only when necessary, then send the new link to everyone.
:::

## Add and publish the wedding date

The first date you save stays private until you publish it.

### Save the date as a private draft

1. Find **Wedding date**.
2. Choose the correct date.
3. Select **Save settings**.

The public website continues to say that the date will be announced until you publish it.

::: warning Changing a date that is already public
If the current date is already published, saving a different date changes the public date immediately. To prepare the new date privately, select **Hide from public** first, change and save the date, then publish it when ready.
:::

### Make the date public

1. Make sure you saved the correct date first.
2. Select **Publish date**.
3. Choose whether to email guests who already received an invitation.
4. Check the date in the confirmation message.
5. Select **Publish**.

The date will then appear on the wedding website, RSVP pages, and future emails.

### Hide a published date

Select **Hide from public**. The date stays saved in the admin area but guests will see that the date is to be announced.

## Update the wedding status

Choose the status that matches the wedding:

- **Planning** — the wedding is still being prepared. Search engines are asked not to list the public website.
- **Date confirmed** — the date is confirmed.
- **Invitations sent** — invitations have been sent.
- **Completed** — the wedding is over. Guests can no longer submit or change an RSVP.

Choose the closest status and select **Save settings**.

Publishing the wedding date automatically changes **Planning** to **Date confirmed**.

## Add the venue and dress code

1. Enter the **Venue name**.
2. Search for or enter the **Venue location**.
3. Add the **Dress code**. Keep the wording clear and helpful.
4. Select **Save settings**.

These details appear on the public site only when a **Details** block is included and its venue or dress-code options are switched on.

## Choose the website theme

The theme controls the public website's colours and overall style.

1. Scroll to the theme choices.
2. Select a theme.
3. Check the example shown on the page.
4. Select **Save settings**.
5. Use **Preview site** to check the complete website.

Changing the theme does not remove your page content.

## Choose the invitation design

1. Scroll to the invitation design section.
2. Choose a design.
3. Choose its light or dark appearance, where available.
4. Check the preview.
5. Select **Save settings**.

Saving prepares the invitation image used when guest invitations are sent by email or WhatsApp.

## Before leaving this page

Check that:

- both names are spelt correctly;
- the public website address is available;
- the date is correct before publishing;
- the venue and dress code are easy to understand;
- the selected theme is readable; and
- you selected **Save settings**.
